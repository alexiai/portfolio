# Alexia Cojan’s portfolio

A collection of my web, mobile, and data science projects, with case studies and a gallery of things I make by hand.

## Run locally

With Node.js 24 and npm installed:

```sh
npm ci
npm run dev:local
```

Open the local address printed in the terminal. Use `npm run build` to build the site or `npm run preview` to preview that build.

## Publish

GitHub Actions builds and deploys the site to GitHub Pages on pushes to `main`. In the repository’s **Settings → Pages**, select **GitHub Actions** as the publishing source.
